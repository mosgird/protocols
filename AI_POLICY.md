# AI policy

This document sets the rules for using generative AI tools when contributing to this repository. It applies to code, specification text, decision records, issues, pull request descriptions, and review comments. It applies equally to every AI tool and every agent, whatever vendor made it.

## Position

Maintainers are critical of generative AI, and that critique shapes the rules below. The concerns are:

- **Energy and water.** Training and running large models uses large amounts of electricity and cooling water.
- **Labor and consent.** Models are trained on work that was made without the consent of its authors or payment to them. Their output can replace the work of the people they learned from.
- **Concentration.** Training and serving large models depends on a few companies with large amounts of capital and compute.
- **Understanding.** Generated output can look correct while being wrong. Relying on it can replace learning the subject.

We accept AI tools for code generation and for a few other bounded tasks where doing the work by hand is costly and the output is easy to check. The accepted uses are:

- **Code generation:** writing or changing code, tests, scripts, and configuration. The author reads, tests, and owns everything submitted.
- **Documentation:** drafting prose that a maintainer then rewrites or edits.
- **Wording:** suggesting alternative phrasing, or pointing out unclear sentences, in text the author wrote.
- **Translations:** a first draft of translated text. A fluent speaker who is not the drafter must review it before it is merged.

We do not accept AI as the source of design decisions, of cryptographic constructions, or of factual claims in the specification. We expect our reliance on these tools to fall as the project matures. This policy will be revised in pull requests as that happens, except for the asset rule below, which is permanent.

## Assets: permanently prohibited

**AI-generated assets are never accepted, and this rule is permanent.** An asset is any image, illustration, icon, logo, photograph, font, sound, music, voice recording, video, 3D model, texture, or animation. This includes placeholders and mockups. It applies whatever the tool and however the output is edited.

The reason is human. The people who make art, music, and sound are paid, or hope to be paid, for that work, and generated substitutes take that work from them. The project does not accept that cost, so the rule does not depend on how the tools change. It is not reopened in pull requests.

Assets made by people are welcome. Their creators keep their own licenses, and the license must be stated in the pull request.

## What you may do

- Use AI tools for the accepted uses listed under Position: code generation, documentation drafts, wording suggestions, and translation drafts.
- Use AI tools to search for or explain published material, provided you verify what they cite.
- Use AI tools to check text you have written, provided you decide what changes to make.

## What you must do

- **Disclose use.** Complete the "AI use" section of the pull request template. Say which tool was used and how: brainstorming, drafted text, generated code, or review only. Disclosure goes in the pull request description. Commit trailers are required as set out under "Commit trailers and session links" below.
- **Confirm no AI-generated assets.** The pull request template asks you to confirm that no asset in the change was generated by AI. This must be ticked "none" in every pull request.
- **Understand what you submit.** You must be able to explain and defend every line in your contribution. If you cannot, do not submit it.
- **Run the checks.** Run `python3 scripts/check_spec.py` and any tests that apply, and report the result honestly.
- **Verify citations.** Check every reference, RFC number, section number, and quotation against the source. Models invent these.

## Commit trailers and session links

- **Session links are banned** in commit messages and in pull request descriptions. Automated checks cover the remote pull request and its commits; keeping local drafts clean is the contributor's responsibility. This covers links to hosted AI sessions or conversations from any vendor (for example, `claude.ai/...`, `chatgpt.com/...`, `gemini.google.com/...`), session identifiers such as `session_...`, `<tool>-session:` lines, and footers such as "Generated with <tool>".
- **If you disclose AI use in a pull request**, every non-merge commit in that pull request must carry two trailers:
  - `Co-authored-by: <tool name> <address>`, naming the tool that contributed. Use the address the tool's vendor publishes for this purpose. For example, `Claude <noreply@anthropic.com>`. Every AI tool gets the same treatment: Claude, Codex, DeepSeek, Gemini, or any other.
  - `Task: <short description>`, at most 120 characters, saying what the tool was asked to do. Do not put secrets, personal data, or private material in it.
- `scripts/check_contributions.py` checks these rules. The `contribution-policy` check runs on every pull request.

## What you may not do

- **Do not generate assets with AI.** This is permanently prohibited. See "Assets: permanently prohibited" above.
- **Do not use AI-generated designs for cryptography or for key handling.** The project references published designs (X3DH, the Double Ratchet, DCGKA, libsodium primitives) and does not invent constructions. AI-assisted edits to these areas must be written or line-by-line reviewed by a human who can check them against the source.
- **Do not paste secrets, private keys, unpublished code, or personal data into an AI tool.**
- **Do not submit output you have not checked.** Unreviewed generated text or code is rejected.

## Review

- Maintainers may ask for a change to be rewritten by hand, or decline an AI-heavy contribution, without a detailed reason. Ask if you want one.
- Pull requests opened by AI agents are reviewed exactly like any other. Agents do not merge (see [AGENTS.md](AGENTS.md)).
- Changes to this policy go through a pull request like any other change. The asset rule may not be changed.

# Test vectors

This directory will hold test vectors for the v0.1 specification: known inputs and expected outputs for key agreement, ratchet steps, MLS epoch derivation, and message encoding.

Vectors are added together with the spec sections they test. This directory is empty until then.

No vectors are provided yet, and none should be taken from an implementation. They will be derived from the referenced documents (RFC 9420, and the Signal X3DH and Double Ratchet specifications) and checked against them.
